# dot morphing: design script

**File:** "dot morphing": 2 pages, 6 artboards each (all named `dot-ground`)

The aesthetic is consistent throughout: blue (#24f) dots on a black background, like a dot-matrix LED display. All shapes are formed by arranging these dots in pixel-art style.

---

## Page 1: desktop (630×360px artboards, arranged in a 3×2 grid)

1. **Plain dot grid**: a filled rectangle of blue dots, no shape, just the raw grid
2. **"waseem"**: name spelled out in dot-matrix lettering
3. **World Trade Center**: WTC silhouette in dot-matrix style; represents New York
4. **Valluvar Kottam**: the Chennai monument, more fully rendered with dome top and internal structure detail; represents Chennai
5. **Fighter jet**: a military jet silhouette, viewed from above/side; represents [idlejet.com](https://idlejet.com)
6. **"ikhtc"**: dot-matrix text; represents [iknowhowtocode.com](https://iknowhowtocode.com)

---

## Page 2: mobile (300×200px artboards, same 3×2 layout, smaller scale)

Exactly the same 6 frames, scaled down for mobile. Same sequence:

dot grid → waseem → World Trade Center → Valluvar Kottam → fighter jet → ikhtc

---

## Overall impression

This is a set of keyframes for a dot-morphing animation. The dots morph between shapes, with the plain dot grid serving as the neutral/resting state that everything morphs from and back to. The `dot-ground` artboard name reinforces this: it's the ground state.

### Sequence meaning

| Frame | Shape | Represents |
|---|---|---|
| 1 | Dot grid | Neutral / resting state |
| 2 | "waseem" | Name / identity |
| 3 | World Trade Center | New York |
| 4 | Valluvar Kottam | Chennai |
| 5 | Fighter jet | idlejet.com |
| 6 | "ikhtc" | iknowhowtocode.com |
